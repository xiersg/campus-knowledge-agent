## 1. 引言

### 1.1 编写目的

本文档描述「校园知识咨询」智能体软件的功能需求与非功能需求，作为开发、测试和课程验收的依据。文档面向：任课教师与助教（验收）、团队成员（开发分工）以及后续使用者（了解产品能力）。

### 1.2 项目背景与需求调研

广东工业大学学生每天需要反复处理几类信息：

1. **查课表**：教务系统（jxfw.gdut.edu.cn）登录流程繁琐，课室、教师、节次分散在多个页面；上课前临时找课室是高频操作。
2. **记考试**：期中、期末、答辩时间散落在各门课的通知里，容易漏记；临近考试没有主动提醒。
3. **复习没抓手**：某一次课讲了什么、课后遗留了什么问题，全凭笔记；学期末想按教学内容复习无从查起。
4. **成绩解读**：教务只给分数列表，不会告诉学生哪几门偏低、该先补什么。
5. **课程资源分散**：想补一门课的知识点，要在 B 站、教材、笔记之间来回切换。

调研结论（面向本班与邻班同学的访谈，共 11 人）：9 人表示「上课前查课室」和「考试前找时间地点」是每周都会发生的操作；8 人希望有一个统一的入口把课表、考试、复盘、成绩放在一起；多数同学不排斥用自然语言和系统对话，但要求**回答必须准确**——课室、时间、分数不能瞎编。

因此本项目不做一个泛泛的聊天机器人，而是做一个**只回答「自己数据里的事实」的智能体**：所有课室、教师、考试时间、教学内容、成绩都必须来自工具查询结果，模型不得凭空编造。

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| 智能体（Agent） | 能理解中文问题、自主选择工具、执行动作并组织回答的程序 |
| MCP | Model Context Protocol，模型上下文协议；本项目中工具以独立进程提供 |
| 工具（Tool） | 智能体可调用的具体能力，如查课表、添加考试，共 16 个 |
| 教务 | 广东工业大学教务系统 jxfw.gdut.edu.cn |
| 复盘 | 对某一次课堂内容的记录（主题、要点、遗留问题） |
| 检索索引 | 基于 BM25 的本地全文索引，覆盖课表、考试、复盘、评价、成绩、记忆 |

## 2. 项目标志与产品定位

### 2.1 项目标志

![项目标志](logo.svg)

标志含义：蓝色渐变圆角方块代表校园与知识；白色对话气泡内的课表网格代表「用对话查课表」的核心交互；右上角的闪电代表智能体「会说也会做」（对话 + 动作执行）。色彩沿用页面主色 `#1d4e89`（深蓝）与 `#4d92f0`（亮蓝）。

### 2.2 产品定位

**一句话定位**：面向广东工业大学学生的校园知识咨询智能体——用中文对话完成课表查询、考试提醒、课堂复盘、课程评价、成绩分析与公开课推荐。

- 产品形态：网页应用（浏览器访问）+ 命令行入口 + MCP 工具进程（可被其他智能体客户端复用）。
- 智能体平台：DeepSeek（OpenAI 兼容接口，可替换为任何兼容模型）；未配置密钥时自动降级为关键词路由，仍可用。
- 试用地址：<http://8.134.98.200:443/>（测试机，系统服务自启）。

### 2.3 范围（做什么 / 不做什么）

**做**：课表导入与查询、考试提醒、课堂复盘、课程评价、成绩导入与分析、课程知识问答、B 站公开课推荐、多用户账号、语音输入与朗读、公网部署。

**不做**（明确排除，避免画大饼）：

- 不做选课、抢课（不调用任何选课接口）；
- 不调用「日在广工」小程序接口（教务数据只走官方教务系统）；
- 不保存教务密码；成绩只允许从教务导入，不允许手记；
- 不做移动端 App、不做社交功能。

## 4. 功能需求

### 4.1 前端功能详述

前端为**单页应用**（`campus_agent/static/index.html`，纯 HTML/CSS/JavaScript，无框架，约 1090 行），通过 `fetch` 调用后端 REST 接口。视觉风格为浅蓝渐变玻璃拟态，响应式布局（900px 以下自动改为纵向排列）。

#### 4.1.1 页面布局

- 顶部横幅：项目标志、「广工资讯」标题、登录按钮、当前账号显示；
- 导航栏：本周课表 ｜ 考试提醒 ｜ 课程评价 ｜ 咨询台；
- 工作区：左侧课表看板（可折叠），右侧咨询台对话面板。

#### 4.1.2 课表看板

- 按星期（一～日）× 节次（12 节，含时间刻度）的网格展示本周课表；
- 今天所在的列高亮；支持「上一周 / 下一周」翻页；
- 点击任一课程格子弹出课程信息窗口：时间、课室、教师、教学内容及最近一次课堂复盘；
- 「今日 / 明日」按钮弹出当日课表清单。

#### 4.1.3 登录与教务导入

- 本站账号注册 / 登录 / 退出弹窗；
- 教务导入三种方式：
  1. **浏览器登录**：点击「打开学校登录页」，在本机浏览器完成统一认证后自动抓取会话、导入课表与成绩（本机使用场景）；
  2. **粘贴 Cookie**：把教务 Cookie 粘贴到输入框导入（服务器上使用的场景）；
  3. **导入刷新**：课表有变动时，用已保存的教务会话一键重新导入，无需重新登录。
- 登录过程中显示同步状态（等待登录 → 读取课表和成绩 → 完成）。

#### 4.1.4 考试提醒面板

- 列出近期考试/答辩：课程、时间、地点、倒计时天数，进入提醒窗口（默认提前 7 天）的条目标注「该提醒了」；
- 展示教务导入的成绩列表；
- 「成绩分析」按钮：显示平均分、偏低课程（75 分以下）、较好课程（85 分以上）与文字结论。

#### 4.1.5 课程评价面板

- 提交表单：课程（带课程名联想）、教师（带教师名联想）、1～5 星评分、评语；
- 结果区按「按课程」「按教师」两张表归类展示。

#### 4.1.6 咨询台（对话面板）

- 两套会话：**校园咨询**（课表、考试、复盘、评价、成绩等一切校园事务）与**课程问答**（每门课一个独立会话，回答被限制在当前课程范围内）；
- 课程问答模式下显示课程选择标签（chips），按课表自动生成；
- 消息按 12 条一页分页展示，滚动到顶部自动加载更早记录；
- 回答中的表格以 Markdown 风格渲染；每条回答下方显示本次调用了哪些工具（工具名 + 是否成功），保证「说出来的话有据可查」；
- **语音输入**：使用浏览器 Web Speech API（webkitSpeechRecognition）把语音转成文字填入输入框；
- **朗读**：可朗读最近一条回答（speechSynthesis）。

#### 4.1.7 前端状态与接口约定

前端不直接读写数据库，全部通过 REST 接口；登录状态由 HttpOnly Cookie（`campus_session`）自动携带；所有接口返回 `{"ok": true/false, ...}` 结构，前端统一处理失败提示。

### 4.2 后端功能详述

后端为 Python 3.10+ 标准库实现（无第三方依赖），模块划分：

| 模块 | 职责 |
| --- | --- |
| `web.py` | HTTP 服务（ThreadingHTTPServer）、路由、账号与教务同步 |
| `agent.py` | 智能体对话循环：模型工具调用、关键词兜底、历史裁剪与压缩 |
| `tools.py` | 16 个业务工具的实现与统一分发（dispatch） |
| `mcp_server.py` / `mcp_client.py` | MCP stdio 服务进程 / 客户端（JSON-RPC 2.0 + Content-Length 帧） |
| `db.py` | SQLite 连接与 12 张表的建表与迁移 |
| `rag.py` | 中文 BM25 检索索引（单字 + 双字 + 英文数字串） |
| `memory.py` | 长期记忆（触发词捕获，最多 30 条） |
| `gdut.py` | 教务系统课表与成绩抓取（官方接口，不碰小程序） |
| `schedule.py` | CSV/JSON 课表解析、周次表达式、学期周换算 |
| `bilibili.py` | B 站公开搜索页解析 |
| `accounts.py` | 注册、登录、登出、会话令牌 |
| `browser_login.py` | 本机浏览器打开教务登录页并捕获 Cookie |

#### 4.2.1 智能体对话循环（agent.py）

处理流程：

1. 接收用户消息与模式（campus 校园咨询 / knowledge 课程问答）；
2. 保存用户消息，捕获长期记忆触发词；
3. **有模型密钥时**：把系统提示（含当前时间、教学周、长期记忆、检索命中的上下文）与最近 8 条历史（约 6000 字上限）发给模型，模型可在最多 **5 轮**内选择调用工具；每次工具调用都把 JSON 结果回填给模型；最终回答若缺少表格则自动补上工具生成的 Markdown 表格；
4. **无密钥或接口失败时**：按中文关键词路由直接调用工具（如「明天」→ 查明天课表，「分析成绩」→ 成绩分析），保证核心功能离线可用，且**绝不编造**课室与分数；
5. 保存回答，超长会话自动折叠：同一会话超过 36 条时，最早的原文压缩成一条长期记忆后删除，保留最近 18 条。

课程问答模式的系统提示将回答范围锁定在当前课程，检索、复盘和 B 站推荐都围绕该课程，避免串课。

#### 4.2.2 工具层（tools.py，16 个工具）

| 工具 | 功能 | 写操作 |
| --- | --- | --- |
| `campus_brief` | 今日/明日课表摘要 + 应提醒的考试 + 当前教学周 | 否 |
| `list_courses` | 按今天/明天/教学周/全部列课，可按关键词过滤、翻周 | 否 |
| `course_detail` | 某门课的教师、课室、时间、教学内容 + 最近复盘 | 否 |
| `upcoming_exams` | 未来 N 天考试，标注是否进入提醒窗口 | 否 |
| `add_exam` | 新增考试/答辩提醒（时间、地点、提前提醒天数） | 是 |
| `list_reviews` / `add_review` | 查看 / 记录课堂复盘（主题、要点、遗留问题） | add 是 |
| `import_schedule` | 导入 CSV 或 JSON 课表（可含考试、复盘） | 是 |
| `load_sample_schedule` | 载入示例课表 | 是 |
| `search_knowledge` | 在课表、考试、复盘、评价、成绩、记忆的索引中检索 | 否 |
| `add_evaluation` / `list_evaluations` | 记录 / 查看课程评价（按课程、按教师归类） | add 是 |
| `list_grades` / `analyze_grades` | 查看成绩 / 百分制分析（平均分、75 分以下弱项、85 分以上强项） | 否 |
| `recommend_courses` | 按主题搜 B 站视频，返回标题、UP 主、播放量、链接 | 否 |

约束：成绩只能由教务导入写入（`import_school_grades`，来源标记 `_source=jxfw`），再次导入只替换教务来源的记录；对话与网页不提供手记成绩入口。所有工具都做参数校验（范围、格式），失败返回 `{"ok": false, "error": ...}`，智能体必须如实说明失败原因，不得假装完成。

#### 4.2.3 MCP 工具服务（mcp_server.py / mcp_client.py）

- 工具以**独立进程**提供，遵循 MCP（2024-11-05）stdio 传输：Content-Length 帧 + JSON-RPC 2.0；
- 支持 `initialize`、`ping`、`tools/list`、`tools/call`；
- 网页与命令行共用同一个 MCP 客户端，调用时附加 `user_id` 实现多用户数据隔离（服务端用 contextvar 传递当前用户）；
- 工具清单即 `TOOL_SPECS`（名称、描述、JSON Schema 参数），既是模型的工具声明，也是 `tools/list` 的返回内容——一份定义，两处使用。

#### 4.2.4 数据与安全

- SQLite（WAL），12 张表：`users`、`sessions`、`user_meta`、`courses`、`exams`、`reviews`、`evaluations`、`grades`、`messages`、`memories`、`chunks`、`meta`；
- 账号数据全部按 `user_id` 隔离；示例账号（id=1）不能密码登录；
- 密码：PBKDF2-HMAC-SHA256，120000 次迭代 + 随机盐，只存哈希；
- 会话：随机令牌存库，Cookie 为 `campus_session`，HttpOnly、SameSite=Lax，有效期 14 天；
- 教务 Cookie 只存服务端 `user_meta`，用于「导入刷新」，**任何接口响应都不返回**；教务密码不保存；
- 请求体上限 1 MB，JSON 严格校验。

#### 4.2.5 教务与外部接口

- 课表：登录统一认证（authserver.gdut.edu.cn）后读取教务个人课表，解析节次时间表（12 节）、周次表达式（`1-16`、`1-8,10`、`1-16单`）、教师、课室、教学内容；
- 成绩：教务成绩接口（总评、平时、期中、期末、学分、绩点与分项分数），带来源标记；
- 推荐：B 站公开搜索页解析，接口无结果时返回搜索页链接兜底。

#### 4.2.6 检索与记忆

- BM25：中文按单字 + 相邻双字切词，英文与数字按整段切词；课表、考试、复盘、评价、成绩、记忆全部进入索引，写操作后自动重建；
- 长期记忆：用户句子含「记住 / 请记得 / 别忘了 / 以后都 / 我喜欢 / 我不喜欢」时写入，最多 30 条；超长对话折叠时也写入压缩记忆。

#### 4.2.7 命令行入口（cli.py）

`python -m campus_agent.cli --demo`：终端内与智能体对话，与网页共用同一套 Agent 与工具。

## 5. 接口需求

### 5.1 REST 接口

| 方法 | 路径 | 用途 | 认证 |
| --- | --- | --- | --- |
| GET | `/` | 返回单页前端 | 无 |
| GET | `/api/health` | 健康检查（是否配置了模型密钥） | 无 |
| GET | `/api/me` | 当前登录用户信息 | 会话 |
| POST | `/api/register` `/api/login` `/api/logout` | 注册 / 登录 / 退出 | 无 / 会话 |
| GET | `/api/overview` | 今日简报（今天明天的课 + 提醒） | 会话 |
| GET | `/api/week?offset=n` | 按教学周取课表（offset 翻周） | 会话 |
| GET | `/api/messages?session_id=&before=&limit=` | 分页取会话消息 | 会话 |
| POST | `/api/chat` | 对话（message、mode、topic、session_id） | 会话 |
| POST | `/api/import` | 导入 CSV/JSON 课表 | 会话 |
| POST | `/api/sample` | 载入示例课表 | 会话 |
| POST | `/api/gdut-sync` | 用粘贴的教务 Cookie 导入课表+成绩 | 会话 |
| POST | `/api/gdut-refresh` | 用已保存的教务会话刷新导入 | 会话 |
| POST | `/api/gdut-browser-sync` | 本机浏览器登录导入（轮询 GET 同名接口取状态） | 会话 |
| GET | `/api/grades?keyword=` | 成绩列表 | 会话 |
| GET | `/api/grade-analysis` | 成绩百分制分析 | 会话 |
| GET/POST | `/api/evaluations` | 评价列表 / 提交评价 | 会话 |

### 5.2 MCP 接口

- 传输：stdio（Content-Length 帧 + JSON-RPC 2.0），协议版本 2024-11-05；
- 方法：`initialize`、`ping`、`tools/list`（返回 16 个工具的 JSON Schema）、`tools/call`；
- 调用 `tools/call` 时由客户端注入 `user_id`，服务端按当前用户执行并返回 `{"ok":..., ...}` 的 JSON 文本。

## 6. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 性能 | 单机可支撑一个班级规模的并发使用；对话历史裁剪保证单次模型请求 ≤ 约 12000 字；消息分页每页 12 条；SQLite WAL 读写不阻塞 |
| 安全 | 密码只存 PBKDF2 哈希；会话 Cookie HttpOnly 14 天；教务 Cookie 不出接口；多用户数据严格隔离；无 SQL 拼接注入点（全部参数化） |
| 可靠 | 模型接口不可用时自动降级为关键词路由，核心查询仍可用；工具失败如实说明；systemd `Restart=always` 崩溃自愈 |
| 可用 | 全中文交互；未配置模型密钥也可演示全部功能；浏览器语音输入与朗读；内置示例课表一键体验 |
| 可维护 | 仅用 Python 标准库，无依赖安装负担；网页、命令行、MCP 共用同一套工具层；17 项单元测试覆盖解析、提醒、导入、多用户隔离、HTTP 对话等 |

## 7. 验收标准

> 说明：验收标准只覆盖 v1.0 已实现并部署的能力，不包含任何规划中但未实现的功能。

| 编号 | 验收项 | 验收标准 | 验证方式 |
| --- | --- | --- | --- |
| A1 | 账号体系 | 可注册、登录、退出；密码不存明文；14 天内会话保持 | 手工 + `test_accounts_do_not_share_schedules` |
| A2 | 课表导入 | 粘贴 CSV 或 JSON 课表后返回导入课程数；示例课表一键载入 | 手工 + `test_exam_reminder_and_import` |
| A3 | 教务接入 | 浏览器登录或粘贴 Cookie 后自动导入个人课表与成绩；「导入刷新」用已保存会话重导 | 手工（本机）/ Cookie 模式（服务器） |
| A4 | 课表查询 | 问「明天有什么课」返回日期、时间、课程、教师、课室、教学内容表格；本周看板按星期×节次展示且可翻周；点课程弹详情 | 手工 + `test_week_page_turns` |
| A5 | 考试提醒 | 列出未来 45 天内考试，进入提醒窗口（≤ remind_days）的条目标注「该提醒了」；可添加考试 | 手工 + `test_exam_reminder_and_import` |
| A6 | 课堂复盘 | 可记录并查询复盘（主题、要点、问题）；课程详情附最近复盘 | 手工 + `test_record_review_roundtrip` |

| A11 | 语音 | 浏览器支持时可用语音输入问题、朗读最近一条回答 | 手工（Chrome/Edge） |
| A12 | 多用户隔离 | 不同账号的课表、对话、评价互不可见 | `test_accounts_do_not_share_schedules` |
| A13 | 上线运行 | `http://8.134.98.200:443/` 公网可访问；服务器重启后服务自动恢复（systemd enabled） | 手工 + 部署检查 |
| A14 | 自动化测试 | `python -m unittest discover -s tests -v` 17 项测试全部通过 | 命令行 |
